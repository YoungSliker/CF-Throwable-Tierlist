# CF 投掷物性能天梯

CF（穿越火线）投掷物性能分级查询网站，基于"笑脸有个梦想"的投掷物性能排行整理。

## 功能

- T0 ~ T7 三级分类（手雷 / 烟雾弹 / 闪光弹）共 165 个投掷物
- 官网武器百科图标
- 搜索跳转：输入名称自动定位，空格/Tab/回车循环切换同名结果
- 跨 Tab 自动切换，匹配项蓝色高亮，当前选中项金色高亮
- 手机端自适应

## 数据

- 数据来源：笑脸有个梦想
- 图标来源：CF 官网武器百科
- 网页搜集制作：YoungSliker

## 本地运行

直接用浏览器打开 `index.html` 即可（需保留 `assets_web/` 目录）。
