# CF 投掷物性能天梯

CF（穿越火线）投掷物性能分级查询网站，基于抖音博主"笑脸有个梦想"的投掷物性能排行整理。

## 在线访问

- H5 网站：https://youngsliker.github.io/CF-Throwable-Tierlist/
- 微信小程序：搜索"CF投掷物天梯"（审核中）

## 功能

- **四大分类**：手雷 / 烟雾弹 / 闪光弹 / 生化手雷，共 184 个投掷物
- **T0 ~ T7 分级**，彩色徽章标识强度
- 图标来源：CF 官网武器百科
- **搜索跳转**：输入名称自动定位，空格/Tab/回车或"下一个"按钮循环切换同名结果
- 跨 Tab 自动切换并高亮，匹配项蓝色边框，当前选中项金色高亮
- **悬浮/点击图标**显示完整名称及性能描述（瞬爆、伤害、特殊效果等）
- 电脑端左图标右文字，手机端图标在上文字在下
- 手机端自适应

> 本项目会随 CF 版本更新持续维护，新投掷物发布后会尽快补充。

## 数据

- 手雷、烟雾弹、闪光弹数据基于博主"笑脸有个梦想"排行整理，生化手雷基于博主游玩测试整理
- 图标来源：CF 官网武器百科
- 网页搜集制作：YoungSliker

## 本地运行

直接用浏览器打开 `index.html` 即可（需保留 `assets_web/` 目录）。

## 微信小程序

- 目录：`mp/`
- AppID：见开发者工具
- 分包加载：主包仅 26KB，手雷/烟雾弹/闪光弹/生化手雷各自独立分包
- 上传命令：`"C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" upload --project <mp路径> --version <版本号> --desc <描述>`
